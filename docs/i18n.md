# i18n Contributions

## Add a new language

1. Fork the repository.
1. Create a branch `i18n-XXX`, where `XXX` is the language you will provide.
1. Create a new file in the `src/locales/` folder, copying `en-US.ts` (translate every key; a missing key falls back to the English text).
1. Edit these files:
    1. `src/locales/index.ts`: add a new export for your file.
    1. `src/app/engines/i18n.engine.ts`: add your language to `availablesLanguages` and in the `init` function.
    1. `src/app/cli/flags.ts`: add your language to the list in the description of the option `--language [language]`.
    1. `src/config/schema.json`: add it to the list in the `language` title.
    1. `docs/configuration.md`: add it to the languages of the `language` option.
1. Push the code to your fork.
1. Create a pull request.

Thanks in advance for your contribution.
